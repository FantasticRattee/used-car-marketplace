The team behind ONE2CAR

ONE2CAR was built by a four-person student team as a web development course project.

    How the site is built

    The front end is plain HTML, CSS and JavaScript served by a small Express server. It talks to a separate Express REST API backed by MySQL.

    • Anyone can browse, search and open listings.
    • Admins log in to add, edit and delete listings. Passwords are stored as scrypt hashes and logins expire after 30 minutes by default.
    • The November 2026 revision added one shared design system, safer rendering of listing text and server-side validation.
